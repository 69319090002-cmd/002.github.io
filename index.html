Project Overview

ระบบตรวจจับเสียงดังและเตือนภัยอัตโนมัติด้วย ESP32 CYD

โปรเจ็กต์นี้ออกแบบสำหรับ ESP32 CYD เพื่อ monitor ระดับเสียงแบบเรียลไทม์ผ่านเซ็นเซอร์เสียง และแสดงผลบนจอ TFT ขนาด 2.8 นิ้วแบบสี เพื่อช่วยติดตามสถานะเสียงแบบทันที พร้อมระบบแจ้งเตือนตามระดับความดัง

วัตถุประสงค์

  • อ่านค่า analog จากเซ็นเซอร์เสียง
  • ตรวจจับสัญญาณเสียงดังจาก digital output (DO)
  • นับจำนวนเหตุการณ์เสียงดังและแสดงผลบนหน้าจอ
  • แสดงสถานะเสียงแบบเรียลไทม์
  • Quiet: สงบ
  • Warning: มีเสียงดังแต่ยังไม่ถึงระดับ alarm
  • Alarm: เสียงดังเกิน threshold
  • ใช้ร่วมกับ PlatformIO ได้ทันที

วิธี build และ upload

1. เปิดโฟลเดอร์โปรเจ็กต์ใน VS Code 2. ตรวจสอบว่า PlatformIO extension ถูกติดตั้งแล้ว 3. รันคำสั่งต่อไปนี้: pio run pio run --target upload
สามารถทำงานผ่าน VS Code Tasks ที่มีอยู่แล้ว เพื่อให้กระบวนการ build และ upload ง่ายขึ้น

การทำงานของโปรแกรม

  • เริ่มต้นด้วยการ initialize จอ TFT และตั้งค่าเริ่มต้น UI
  • วนลูปอ่านค่า analog จาก AO และ state จาก DO
  • เมื่อ DO เปลี่ยนจาก HIGH เป็น LOW จะนับว่าเกิดเหตุการณ์เสียงดังขึ้น
  • หากมีเสียงดังต่อเนื่องเกินช่วงเวลา จะรีเซ็ตตัวนับ
  • ระบบคำนวณสถานะตามค่า analog และจำนวนเหตุการณ์

สถานะที่แสดงผล

  • QUIET — สงบ
  • WARNING — มีเสียงดังแต่ยังไม่ถึงระดับ alarm
  • ALARM — เสียงดังเกิน threshold
if (soundHits >= 5 || analogVal > 2800) { currentState = 2; // Alarm } else if (soundHits >= 1 || analogVal > 2000) { currentState = 1; // Warning }

หมายเหตุและสรุป

  • วงจรนี้ใช้ ESP32 CYD บน PlatformIO
  • อาจต้องปรับค่า pin และความสว่างของหน้าจอให้เข้ากับอุปกรณ์จริง
  • ถ้าแต่ละหน่วยของเซ็นเซอร์มีระดับ noise ต่างกัน ควรปรับ threshold ให้เหมาะสม
  • โปรแกรมนี้เป็นตัวอย่างการใช้งาน ESP32 CYD ร่วมกับเซ็นเซอร์เสียงและจอ TFT เพื่อแสดงสถานะเสียงแบบเรียลไทม์ พร้อมระบบเตือน warning และ alarm
